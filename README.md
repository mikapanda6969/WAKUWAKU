# 今日のわたし日和

生年月日から、肯定的な褒め言葉と今日の暦メッセージ、ラッキーカラー、ラッキーアイテムを表示するスマートフォン向けWebアプリです。外部APIやビルド作業は不要です。

## ファイル構成

```text
WAKUWAKU/
├── index.html   # 画面の構造
├── styles.css   # レスポンシブデザイン
├── app.js       # 暦計算・文章選択・画面操作
└── README.md    # この説明書
```

## 起動方法

### 手軽な方法

`index.html` をブラウザで開いてください。

### ローカルサーバーを使う方法（推奨）

Python 3 が入っている環境で、プロジェクトのフォルダーに移動して実行します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。入力情報はサーバーや外部APIへ送信されません。

## 占い計算部分の仕様

### 毎日の固定値

生年月日と端末上の今日の日付を組み合わせてFNV-1aハッシュを作り、ラッキーカラー、アイテムなどの選択に使用します。そのため同じ日・同じ生年月日なら再読み込みしても基本結果は同じで、日付が変わると結果も変化します。褒め言葉だけはボタンを押すたびに選択用の値を進め、重複しない3文を選び直します。

### 四柱推命（生年月日だけで見る簡易版）

グレゴリオ暦をユリウス通日（JDN）に変換し、`(JDN + 49) mod 60` を甲子=0とする一般的な六十干支の日柱計算法から、出生日時点と今日の十干を求めています。その関係に対応する、わかりやすく前向きな文章を表示します。

本格的な四柱推命では出生時刻・出生地、節入り時刻なども扱います。本アプリは出生時刻と出生地を入力しないため、時柱や厳密な月柱を含む「正確な鑑定」ではありません。結果画面にも「生年月日だけで見る簡易版」と表示します。

### マヤ暦

Dreamspell（13の月の暦）方式の260日周期を採用しています。2012年12月21日を KIN 207 とする既知の対応を基準に、次式でKIN番号を算出します。

```text
KIN = ((JDN + 143) mod 260) + 1
```

出生KINと今日のKINを13テーマの循環に重ね、今日のテーマとおすすめ行動を選びます。古代マヤ暦には複数の相関・現代的解釈があるため、これはDreamspell方式による日々を楽しむための簡易メッセージであり、科学的な予測や正確な鑑定をうたうものではありません。

## 初心者向けの変更ポイント

- 褒め言葉を追加する：`app.js` の `PRAISES` に文章を追加
- 今日の一言を変える：`SHICHU` の文章を編集（10件の順序は維持）
- マヤ暦の文章を変える：`MAYAN_THEMES` と `MAYAN_ACTIONS` を編集
- 色やアイテムを増やす：`COLORS` または `ITEMS` に同じ形式で追加
- デザインを変える：`styles.css` 冒頭の `:root` にある色変数を編集

## 今後追加できる機能

- 誕生日を端末内だけに保存する「次回から入力を省略」機能
- 過去のメッセージを振り返るカレンダー
- 出生時刻・出生地と節入り計算を追加した四柱推命の詳細表示
- 画像付きのシェアカード生成
- 文字サイズ切り替え、読み上げなどのアクセシビリティ機能
- PWA化によるホーム画面への追加とオフライン対応
